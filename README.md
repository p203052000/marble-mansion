# 豪宅彈珠大賽

51 顆彈珠、5 個房間、1 個冠軍。你是其中一顆彈珠，在豪宅裡用砧板、精裝書、沙發坐墊、大理石洗手檯和三角鋼琴做成的軌道上比賽，每關淘汰一批，最後衝過終點的就是冠軍。

## 怎麼玩

- 電腦：← → 或 A / D 左右閃，空白鍵使用道具，Esc 暫停，M 開關音樂
- 手機：按住螢幕左右兩側轉向，右下角按鈕使用道具

## 內容

- 五個房間：廚房、書房、客廳、浴室、宴會廳，每間有不同的軌道手感和機關
- 加速板、跳台、傾斜彎道
- 五種道具：香檳軟木塞、肥皂泡泡、羽毛、鉛錘、鬧鐘
- 三種難度

整個遊戲是單一 HTML 檔，用 three.js 繪製，畫面材質和音樂都是程式即時產生的。
